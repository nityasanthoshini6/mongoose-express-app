
# Express Mongoose App

A Node.js application built using Express.js and MongoDB with Mongoose.

## Live Demo

🚀 **Live Application:** https://mongoose-express-app-yeh9.onrender.com/

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv

## Project Structure

```text
express-mongoose-app/
├── node_modules/
├── .env
├── .gitignore
├── package.json
├── package-lock.json
├── server.js
├── test.js
└── README.md
```

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/express-mongoose-app.git
```

Navigate to the project directory:

```bash
cd express-mongoose-app
```

Install dependencies:

```bash
npm install
```

## Environment Variables

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
PORT=3000
```

## Run the Application

```bash
node server.js
```

The application runs locally at:

http://localhost:3000
